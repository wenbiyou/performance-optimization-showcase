# 📋 优化前 - 基准版本

这是**优化前**的基准版本，刻意保留了真实业务项目中常见的性能问题，用于对比优化效果。

## 🐛 刻意植入的性能问题

1. **图片问题**：3 张高清 PNG 图片未压缩，总体积 1.8MB，全部首屏同步加载
2. **路由问题**：所有路由**同步导入**，全部打包进首包
3. **第三方依赖**：全量引入 `lodash`，不是按需导入
4. **长列表**：1000 条数据一次性全部渲染，无虚拟滚动
5. **构建优化**：无分包、无压缩配置
6. **资源策略**：无预加载、无延迟加载、无缓存策略

## 📊 基准性能数据（Slow 3G）

| 指标 | 数值 |
|------|------|
| 首屏加载时间 | **10.2s** |

## 🚀 本地运行

```bash
pnpm install
pnpm dev
# 访问 http://localhost:3001
```

## 🧪 性能测试方法

1. Chrome 无痕窗口
2. DevTools → Network → Throttling → Slow 3G
3. 勾选 Disable cache
4. 刷新，记录加载时间
